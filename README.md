# QR受付システム (QRReceptionSystem)

庁内ネットワークで利用する、**静的HTML・JavaScriptのみのQR受付システム**。バックエンド・外部API・CDN・インターネット接続は使いません。

## 使い始める

1. このリポジトリをZIPで取得し、ファイルと `vendor/` を同じディレクトリ構造で庁内Webサーバーに配置する。
2. **`index.html` を開く**（`app.html` に移動）。
3. 総合管理画面で「＋ 新規イベント」を作成し、事前準備で参加者を登録する。
4. 事前に参加者のQRを発行し、当日は「受付」から受付区分を選択してQRを読む。
5. 重要な変更・イベント終了のタイミングで「全イベントJSONバックアップ」を保存する。

**必ず実際の庁内PC・Webサーバーで事前検証してください。** 旧検証版では現在の環境でHTTPカメラ読み取りを確認済みですが、異なるブラウザ・端末ではHTTPS等のセキュアコンテキストを要求する場合があります。

## 初期実装の範囲

| 項目 | 状態 |
| --- | --- |
| 総合管理／イベント一覧 | 実装済み（開催日・イベントIDの昇降順、日付範囲・イベント名の絞り込み） |
| イベント作成・複製・削除 | 実装済み。複製は設定だけ、名簿・受付結果はコピーしない |
| イベント設定 | 実装済み（開催日・分類・区分の追加／名称変更・任意2項目） |
| 参加者登録 | 実装済み（個別・CSV、職員番号の重複回避、参加区分設定） |
| QRコード | イベント専用の識別子による**個別表示・PNG保存**、A4印刷用プレビューまで実装 |
| 当日受付 | カメラによるQR照合、重複防止、区分別タイムスタンプ、手動受付、飛び入り追加、受付取消 |
| 未受付者一覧 | 事前登録・参加対象・未受付の人を選択中の区分ごとに自動表示 |
| localStorage | イベント単位のデータ保存。PC・ブラウザプロファイル・オリジンごと |
| JSON | 全イベントの一括バックアップ、形式検証・重複確認付き復元 |
| CSV出力 | 名簿、イベントごとの区分別結果、横断参加者一覧、横断区分別詳細、メール宛先対応表 |
| ヘルプ | [help.html](./help.html) に独立した操作案内 |
| メール用QR一括ZIP生成 | **未実装**（宛先CSV・個別PNGは使用可能） |
| QRの職員共通化／複数PC同期／アクセス認証 | 未実装・将来検討 |

**注意:** 現段階は初期実装です。実データの受付に使う前にテストデータで読取、印刷、CSV、JSONバックアップと復元を通しで確認してください。アプリの実ブラウザでの完全な動作検証はまだ完了していません。

## 保存と復元

- 保存先は `localStorage` の `QRReception:index:v1`（ID一覧）と `QRReception:event:v1:<イベントID>`（イベントごと）。
- JSONはバックアップ用で、個人情報・発行済みQRの識別子・受付履歴・採番情報を含む。ファイルは庁内ルールに従い厳重に管理する。
- 復元では既存のイベントを**保持（既定）／上書き**から選ぶ。上書きすると既存の受付履歴が差し替わるため確認画面を設けている。
- CSVはExcel用。参加者一覧はイベント×参加者、区分別詳細はイベント×参加者×受付区分が1行。
- **全イベントJSONの対象はイベント一覧の検索条件とは無関係**。同じオリジン内のアプリが管理するすべてのイベントを出力する。
- 旧 `scanner-prototype.html` のデータは別の保存領域なので、新アプリのデータへ自動移行しない。

## CSV参加者登録

- 最低限 `氏名` または `name` 列を用意する。
- 任意の列名：`職員番号` / `staff_id`、`所属` / `department`、`メール` / `email`、設定した任意項目の表示名。
- 受付区分名（例：`午前`、`午後`）を列見出しにし、参加予定は `○` または `1` 等で指定する。
- 1区分だけのイベントでは区分列がなければ全員を参加対象にする。**複数区分がある場合、区分列を省略するとその区分は参加対象外**になる。
- UTF-8（BOM対応）。Shift_JISは文字化けを検知した場合に代替デコードを試みる。
- 職員番号が既存の人と重複する場合、その行を飛ばす。既存データの一括更新は未実装。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ入口（`app.html` へ遷移） |
| `app.html`・`app.css`・`app.js` | 実際に保存・操作する初期実装 |
| `help.html` | ヘルプ・操作説明 |
| `wireframe.html` | 旧デザイン検証用（データ保存はしない） |
| `scanner-prototype.html` | 従来のQR読み取り検証版（独立した保存領域） |
| `issue.html` | 単票QR発行検証版（本アプリの名簿とは連動しない） |
| `vendor/` | QRコード読取・生成用ライブラリ（各ライセンス同梱） |
| `docs/基本方針.md` | 設計上の決定事項・今後の拡張方針 |

既存の試作品を残すため、新しいアプリ用に `app.*` を追加しています。
