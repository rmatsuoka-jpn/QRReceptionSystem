# QRReceptionSystem

閉域ネットワーク内で使う、静的HTMLベースのQR受付システム（初期検証版）。

## 想定環境

- インターネット接続不要。HTML・JavaScript・QRライブラリをすべて同梱。
- 庁内Webサーバーにフォルダごと配置し、受付PCのブラウザから利用する。
- 1つの受付につき受付PCは1台。複数端末間のリアルタイム同期は対象外。
- Webサーバーは静的ファイル配信のみ。バックエンド、外部API、データベースは使用しない。

## 起動方法

1. GitHubの **Code → Download ZIP** でリポジトリを取得する。
2. ZIPを展開して、`index.html`、`issue.html`、`wireframe.html`、`help.html`、`vendor/` が同じ構成になるようフォルダごと庁内Webサーバーにコピーする。
3. 庁内Webサーバーから開き、`wireframe.html` で画面構成、`index.html` でQR読み取り、`issue.html` でQR発行の検証を行う。

**カメラ利用の注意：** 現行の庁内環境ではHTTPでの読み取り動作を確認済みです。一方、一般的なブラウザではカメラ利用にHTTPSなどの安全なコンテキストを求める場合があります。端末・ブラウザ・配信先の変更時には別途動作確認してください。

## 操作ワイヤーフレーム（画面設計確認用）

- [wireframe.html](./wireframe.html) を開くと、**総合管理 → 事前準備／当日受付**の画面構成を確認できる。右上の **[ヘルプ・操作説明](./help.html)** から独立した1ページの操作案内を開ける。
- トップは**総合管理画面**。イベント管理（新規作成・選択・設定複製・削除）、横断参加者検索・抽出、データ管理（全イベントJSONバックアップ／復元）の3領域に分ける。
- 横断参加者検索では年度（4月～翌3月）／暦年／全期間、イベント分類、氏名・職員番号・所属、受付状況による**サンプルデータの絞り込み**を試せる。参加者一覧はイベント×参加者で1行、区分別詳細はイベント×参加者×区分で1行とする（CSVファイル生成は未実装）。
- イベント一覧では新規作成・過去イベントの選択・設定複製・削除に加え、**開催日・イベントIDの昇順／降順ソート、イベント名・開催日範囲による絞り込み**をサンプルデータで試せる。フィルタを解除しても並び替えは維持する。
- 出力メニューとトップの「全イベントJSONバックアップ」は、イベント一覧の絞り込み結果に関係なく全イベントを対象とする設計（ファイル生成は未実装）。
- イベントカードの開催日を大きく表示し、当日受付モードでは**カメラ下に受付者の氏名を大きく表示**する。右側（狭い画面では下側）に**選択中の区分でまだ受付していない事前登録者**の氏名・所属・人数を常時表示する。受付操作・区分切替・手動受付・取消・名簿修正に連動して自動更新する。
- 当日受付モードでは「飛び入り参加者の登録と受付」「参加者検索」「QR忘れ時の手動受付」「区分の参加対象変更」「受付取消」を**サンプルデータで模擬操作**できる。
- 画面設計を確認するための独立した試作品。**カメラ読み取り、QR一括発行、CSV取込、localStorageへの保存は行わず、再読み込みで内容を初期化する。**
- 実際のカメラ読み取り検証は `index.html`、QR単票発行の検証は `issue.html` を利用する。実運用を始める前にこれらを統合する予定。

## 現在の検証機能

- `index.html`：カメラまたは画像ファイルでQR読み取り、同一QRの重複登録防止、受付時刻記録、件数・一覧、CSV出力、クリア。
- `issue.html`：受付番号を手入力してQRコードを1件生成、PNG保存または印刷。
- データは受付PCの**ブラウザ内 localStorage** に保存される。同じオリジン／ブラウザプロファイルで再開すれば復元できることを想定しているが、ブラウザデータの消去や管理ポリシー等によって失われる可能性がある。毎回CSV出力すること。
- 名簿照合、名簿CSV取り込み、一括発行、受付データのインポート復元、イベントごとの分離、権限管理は未実装。

**注意：現段階は仕様確認用プロトタイプであり、実際の受付運用には利用しないこと。** QRの内容は本人認証ではなく、番号の重複確認のみ。受付台帳を別イベントと使い回す場合はCSV出力後にクリアが必要。

## ライブラリ

`vendor/` に外部CDN不要のライブラリ本体を同梱。

| 用途 | ライブラリ | ライセンス |
| --- | --- | --- |
| 読み取り | [html5-qrcode 2.3.8](https://github.com/mebjas/html5-qrcode) | Apache-2.0 (`vendor/LICENSE-html5-qrcode.txt`) |
| 発行 | [qrcodejs](https://github.com/davidshimjs/qrcodejs) | MIT (`vendor/LICENSE-qrcodejs.txt`) |

ライブラリを差し替える場合は、動作確認・セキュリティ確認・ライセンス確認を行うこと。
