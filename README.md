# QRReceptionSystem

閉域ネットワーク内で使う、静的HTMLベースのQR受付システム（初期検証版）。

## 想定環境

- インターネット接続不要。HTML・JavaScript・QRライブラリをすべて同梱。
- 庁内Webサーバーにフォルダごと配置し、受付PCのブラウザから利用する。
- 1つの受付につき受付PCは1台。複数端末間のリアルタイム同期は対象外。
- Webサーバーは静的ファイル配信のみ。バックエンド、外部API、データベースは使用しない。

## 起動方法

1. GitHubの **Code → Download ZIP** でリポジトリを取得する。
2. ZIPを展開して、`index.html`、`issue.html`、`vendor/` が同じ構成になるようフォルダごと庁内Webサーバーにコピーする。
3. Webサーバーから **HTTPS** で開き、`index.html` でQR読み取りを、`issue.html` でQR発行を確認する。

**重要：カメラによるQR読み取りは安全なコンテキストが必要。** 庁内の別PCから `http://server/...` のようにアクセスした場合、一般的なブラウザではカメラが使えない。`https://server/...` にする（PCが証明書を信頼する必要がある）。`localhost` での試験は例外。ライブラリをローカルに置くだけではこの制限は解消しない。

## 現在の検証機能

- `index.html`：カメラまたは画像ファイルでQR読み取り、同一QRの重複登録防止、受付時刻記録、件数・一覧、CSV出力、クリア。
- `issue.html`：受付番号を手入力してQRコードを1件生成、PNG保存または印刷。
- データは受付PCの**ブラウザ内 localStorage** に保存される。同じオリジン／ブラウザプロファイルで再開すれば復元できることを想定しているが、ブラウザデータの消去や管理ポリシー等によって失われる可能性がある。毎回CSV出力すること。
- 名簿照合、名簿CSV取り込み、一括発行、受付データのインポート復元、イベントごとの分離、権限管理は未実装。

**注意：現段階は仕様確認用プロトタイプであり、実際の受付運用には利用しないこと。** QRの内容は本人認証ではなく、番号の重複確認のみ。受付台帳を別イベントと使い回す場合はCSV出力後にクリアが必要。

## ライブラリ

`vendor/` に外部CDN不要のライブラリ本体を同梱。

| 用途 | ライブラリ | ライセンス |
| --- | --- | --- |
| 読み取り | [html5-qrcode 2.3.8](https://github.com/mebjas/html5-qrcode) | Apache-2.0 (`vendor/LICENSE-html5-qrcode.txt`) |
| 発行 | [qrcodejs](https://github.com/davidshimjs/qrcodejs) | MIT (`vendor/LICENSE-qrcodejs.txt`) |

ライブラリを差し替える場合は、動作確認・セキュリティ確認・ライセンス確認を行うこと。
